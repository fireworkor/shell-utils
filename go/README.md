# Go (Golang)

## 简介
Go 是 Google 开发的开源编程语言，专注于简洁、高效和并发。

## 使用命令

```bash
# 安装特定版本
bash go.sh 1.21
bash go.sh 1.22

# 查看版本
go version

# 设置 GOPATH 和 GOROOT
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
```

## 常用命令
```bash
go build       # 编译
go run         # 运行
go test        # 测试
go get         # 获取包
go mod         # 模块管理
```

📝 常用端口参考

                    

                        
                            
端口说明建议

                        
                        
                            
5000WebUI 默认端口开发测试使用

                            
8080常见 HTTP 端口需要配合反向代理

                            
80标准 HTTP 端口需要 root 权限或反向代理

                            
443标准 HTTPS 端口需要配置 SSL 证书

                            
3000Node.js 默认端口避免与其他服务冲突

                            
8888常见自定义端口易于记忆

# Python

## 简介
Python 是一种简单易学、功能强大的编程语言。

## 使用命令

```bash
# 安装特定版本
bash python.sh 3.11
bash python.sh 3.10

# 查看版本
python --version
python3 --version

# pip 安装
pip install package_name
pip install -r requirements.txt
```

## 相关命令
- pip 或 pip3: Python 包管理器
- virtualenv: 虚拟环境
- conda: Anaconda 包管理器

# Node.js

## 简介
Node.js 是基于 Chrome V8 引擎的 JavaScript 运行环境。

## 使用命令

```bash
# 安装特定版本
bash nodejs.sh 18
bash nodejs.sh 20

# 查看版本
node --version
npm --version

# 包管理
npm install package_name
npm install -g package_name
npm install --save package_name
```

## 相关工具
- npm: Node Package Manager
- yarn: 另一个流行的包管理器
- nvm: Node Version Manager
